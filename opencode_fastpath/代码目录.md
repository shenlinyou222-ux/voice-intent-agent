# 完整代码目录（逐文件 / 逐补丁 / 参数索引）

> 生成：opencode ｜ 2026-10-19 ｜ 目标：把这套「语音意图识别」从头到尾过一遍

## 0. 建议的阅读顺序（从入口到细节）

1. **入口**：`aoe4\run_voice_aoe4.cmd` → `aoe4\run_voice_aoe4.ps1` → `voice_agent.py`（打补丁后）
2. **一次说话的主干**（都在 `voice_agent.py`）：`run_mic()`（采集/队列/看门狗）→ `Seg`(VAD) →
   `_a_flush/_a_worker`（A 路：裁剪→ASR→快路径）→ `handle()`（B 路：SNR→ASR→意图→动作/听写）
3. **我们的层**：`opencode_fastpath\`
   `intents.py`（唯一开关）→ `runtime.py`（A/B 路接入+假命中护栏）→ `fastpath.py`+`pinyin.py`（掩码）→
   `reply.py`（统一返回）→ `hook.py`（开关解析）→ 其余功能模块
4. **VAD/校准**：`vad_silero.py`（引擎+AGC）→ `opencode_fastpath\vad_adapt.py`（三套自适应）→
   `vad_action.py`（单句校准）→ `vad_calib.py`（批量校准）
5. **配置与状态**：`intent_config.json`（唯一清单）→ 两个 profile → `domain_state.json` / `vad_profiles.json`
6. **校验/回滚**：`opencode_fastpath\selfcheck.py`、`patch.py --status/--rollback`、`ROLLBACK.md`
